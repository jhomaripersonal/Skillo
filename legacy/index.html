Install any skill

The command on each card copies one skill folder into your project's .claude/skills/ (use .agents/skills/ for Codex). No account needed.

Install as a plugin

Many repos also ship as plugins. In Claude Code, for example: /plugin marketplace add anthropics/skills. Or use npx skills add owner/repo from skills.sh.

Licenses

Each card shows the license from the skill or its repo. “Unspecified” means no license file was found — check the repo before reusing it.

Review before you install

Skills can include scripts your agent will run. Read the SKILL.md and any bundled files first, especially from community sources.
